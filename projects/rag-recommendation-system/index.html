AI-Powered RAG Recommendation System

Last updated 24 Oct 2026 · 1 min read

Role
Author (Bachelor's thesis)
Timeline
2024
Status
◌ Archived
Stack
LangChain · LangGraph · +2

TL;DR

My Bachelor's thesis, a retrieval-augmented recommender that explains its suggestions, with lexical, vector and hybrid search compared on ranking metrics and an LLM-as-judge.

Problem #Link to section Problem

Retrieve context and generate personalized explanations for recommendations, and reduce LLM hallucinations.

Data #Link to section Data

The context that the hybrid search system (BM25 + Vector) retrieves, with FAISS for vector storage.

Approach #Link to section Approach

An end-to-end RAG pipeline. A hybrid search system (BM25 + Vector) built with LangChain and LangGraph retrieves context and generates personalized explanations; FAISS for vector storage; prompts iteratively optimized to reduce LLM hallucinations.

Result #Link to section Result

The model was deployed via FastAPI. Retrieval quality was benchmarked using ranking metrics (Precision@k, Recall@k, NDCG, MRR) alongside an LLM-as-judge framework to compare lexical, vector and hybrid search configurations.
